# S04 — Azure boundaries and access

- **When:** Week 02, Monday
- **Skills:** DEV-02, ARC-01
- **Prerequisites:** S01, S03
- **Status:** Not started

## Desired outcomes

1. Draw storage, network, identity, control-plane, and data-plane boundaries for the target path.
2. Explain why a selected human, workload, or CI identity can access one resource and cannot access another.
3. Identify the minimum reporting/serving access path and the sensitivity controls it requires.

## Observable evidence

- An access matrix linking identities, scopes, roles, network paths, and allowed actions.
- Two narrated access scenarios: one permitted and one deliberately denied.
