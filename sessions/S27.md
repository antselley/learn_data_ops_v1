## Desired outcomes

1. Link a training run to immutable or versioned data identity, code revision, configuration, dependency lock, validation design, parameters, metrics, and artefacts.
2. Track comparable baseline and candidate runs in MLflow and define model-version naming or registry semantics.
3. Reproduce an earlier evaluation from recorded inputs rather than notebook state.

## Observable evidence

- Two traceable runs and a lineage checklist covering every reproducibility input.
- A clean-environment or independent rerun whose evaluation matches within a stated tolerance.
