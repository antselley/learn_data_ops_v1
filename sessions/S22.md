# S22 — Databricks value and lock-in

- **When:** Week 08, Monday
- **Skills:** DEV-05, ARC-05
- **Prerequisites:** S18, S21
- **Status:** Not started

## Desired outcomes

1. Evaluate Databricks features for orchestration, governance, observability, recovery, collaboration, and performance against actual team needs.
2. Compare total cost and maintenance effort for a small predictable workload and a larger variable workload.
3. Define portability boundaries and an exit/recovery path for managed features that hold state or affect data publication.

## Observable evidence

- A capability/cost matrix with explicit usage assumptions and licence-versus-compute separation.
- A managed-feature adoption decision including operational owner, failure mode, and exit trigger.

See [week 8 reading](../READING.md#week-08) for Databricks architecture, cost, and reliability guidance.

## Stopping point

Stop at two scenario decisions and their assumptions; exact pricing should be refreshed only when a deployment is considered.
