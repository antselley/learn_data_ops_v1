- **When:** Week 01, Wednesday
- **Skills:** DEV-03

## Desired outcomes

1. Define a reproducible local dependency strategy and when a container improves consistency versus adding friction.
2. Specify useful developer commands for setup, test, lint/validate, run, and clean.
3. Design small synthetic test data and automated checks that exercise the selected path without real sensitive data.

## Observable evidence

- A local-tooling decision note with dependency/lock-file and container boundaries.
- A command contract and test-data specification another engineer could follow.
