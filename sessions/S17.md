# S17 — Azure batch and serving design

- **When:** Week 06, Wednesday
- **Skills:** DEV-02, ARC-01, ARC-03
- **Prerequisites:** S04, S10
- **Status:** Not started

## Desired outcomes

1. Select an affordable Azure batch-compute pattern from workload duration, frequency, scale, networking, identity, recovery, and scale-to-zero needs.
2. Define least-privilege access from source through storage/compute to a supported reporting or data-serving path.
3. Compare at least two serving choices for concurrency, freshness, semantic stability, and operating effort.

## Observable evidence

- An Azure architecture diagram with identities, network paths, state, and data boundaries.
- A decision record tying compute and serving choices to quantified requirements and unknowns.
