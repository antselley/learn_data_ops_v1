# Learning journal and retrospectives

Use this area for reflections that span sessions: patterns in mistakes, changes in judgement, cost heuristics, or what to repeat next. Session-specific reflections stay in the individual `sessions/Sxx.md` record.

Create entries as `YYYY-MM-DD-short-title.md` using [`TEMPLATE.md`](TEMPLATE.md). Good entries are concise and evidence-led. They distinguish:

- what happened;
- what the evidence supports;
- what remains uncertain;
- what will change next time.
